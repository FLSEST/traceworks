# Logo

The sign is a trace: a line in steps that ends in a result.

| File | Use |
|---|---|
| `traceworks-logo.svg` | the sign beside the name |
| `traceworks-logo-stacked.svg` | the sign above the name |
| `traceworks-mark.svg` | the sign alone |
| `traceworks-mark-mono.svg` | the sign in one colour: it takes the colour of the text around it |
| `traceworks-icon.svg` | the sign in a filled field, for a favicon or a profile picture |
| `traceworks-scheme.svg` | how a run is built, with a legend |

Each file but the one-colour sign follows the viewer's light or dark setting by itself. The letters are paths, so no
file needs a font: the name is set in Space Grotesk, the legend in IBM Plex Mono, both under the SIL Open Font
License.

Colours: ink `#14232b`, paper `#e9f0f1`, the result `#0b7a75` (on dark `#45c9bd`), the optional line of the scheme
`#c96f1e` (on dark `#f2a655`).

The name and the logo are not covered by the license of the code (see `NOTICE`).
